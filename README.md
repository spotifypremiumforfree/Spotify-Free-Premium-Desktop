## How to use
1. Download v1.2.99.317.
2. Extract `Spotify-Free-Desktop.zip`.
3. Sign in.
4. Pick a playlist. Play.

## FAQ

**Shuffle only?**
Desktop free is on-demand. Ads stay. Notes in `files/play/`.

**Offline?**
Downloads are Premium. This zip is the free desktop player.

## Requirements
Windows 10/11. Spotify account.
